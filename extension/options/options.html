Phishing URL Detector Settings

Configure local communication between your Firefox browser and the offline Python service.

Local Service Endpoint

Security policy: Must be a loopback HTTP address (e.g. http://127.0.0.1:8000 or http://localhost:8000). Remote addresses are prohibited to preserve your browsing privacy.

Authentication Token

The service generates a secret token upon startup to prevent unauthorized local processes from abusing the scanner. You can copy your token from: cat data/processed/service_token or from the terminal logs when running python -m detector_service.

Detection Options

Inspects domain age and DNS records via local cached lookups.

Fetches and analyzes web page content when Layers 1–3 land in the uncertain band.

Privacy & Localhost Threat Model

  • Local Only: All URL scans are sent exclusively to your local machine at 127.0.0.1. No external servers or telemetry are used.
  • Token Protection: The token is stored locally in Firefox's browser.storage.local. It is never transmitted to websites you visit.
  • Threat Model: This token defends against unauthorized cross-origin web scripts or untrusted local users. Any process running as your local OS user with disk access can read stored configuration.
